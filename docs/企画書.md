# ご当地ピン（仮） 企画書

2026-10-22 作成、2026-10-24 更新。riku の「日本の特産品クイズ」「ジオゲッサーみたいに地図にピンを指す」から。

## コンセプト
特産品・建造物・ご当地もの・アニメ漫画のゆかりの地が出題され、日本地図の上で「ここ！」とピンを刺す。正解地点との距離でスコアが決まる、日本ご当地版ジオゲッサー。

- 対象: PC（ブラウザ）。当面はブラウザ版で完成させる（2026-10-24 決定）
- 類似作: 都道府県タップ型の学習アプリ（正誤のみ）、海外の FoodGuessr（世界の料理）。「日本のご当地×距離スコア×市までの判定」が差別化ポイント

## 1ラウンドの流れ
1. お題が出る（例「夕張メロン」「姫路城」「赤べこ」「スラムダンクの踏切」）
2. 地図をホイールで拡大・ドラッグで移動し、クリックでピン。拡大すると市町村の境界が出る
3. 「ここに決定」で答え合わせ。正解地点とピンを線で結び、距離を表示
4. 5問で1ゲーム。合計点でランク（これから旅に出よう → 見習い旅人 → 旅好き → ご当地通 → ご当地マスター）

## 得点（現状）
- 距離点 = 5000 × exp(−距離km / 150)
- 県ピタ（正解の都道府県内）: +500
- 市ピタ（正解の市内）: +1500
- ヒント倍率: 使った段階に応じて合計に ×0.9 / ×0.7 / ×0.5
- 1問の満点 7000、1ゲーム 35000
- ランクは5問換算の点数で判定（ジャンルと地方の組み合わせで5問に満たないときも同じ基準）

## ヒント（3段階、順番に開く）
1. 地方（例: 近畿）
2. 都道府県
3. どんな市か（例: 「港と異人館のまち」）

## 出題データ
- `data/questions.tsv`。答えは必ず「市」（町村は使わない。東京は特別区）
- ジャンル: 特産品 45 / 建造物 22 / ご当地もの 12 / アニメ・漫画 19（計98問）
- ジャンル選択（すべて／各ジャンル）と地方選択（地方縛り）あり

## モード
- ふつう: 5問、制限時間なし
- タイムアタック: 1問20秒。残り1秒につき +50（ヒント倍率はかけない）。時間切れでピンがあればそれで決定、なければ0点。1ゲームの満点 40000
- デイリー: 日付から決まる同じ5問（全ジャンル・全地方）。記録するのはその日の1回目だけ。結果を絵文字（🟧市ピタ 🟨県ピタ ⬛それ以外）でコピーできる
- 地方縛り: ヘッダーの「地方」で選ぶ。北海道・東北 / 関東 / 中部 / 近畿 / 中国・四国 / 九州・沖縄（北海道と四国は問題が少ないので隣とまとめた）

## やり込み要素
- 図鑑: 一度出たお題がカードになり、最高点と県ピタ・市ピタが残る。未出題は「？？？」
- 地図の塗り: 図鑑を開くと、県ピタを取った県が黄色、市ピタを取った市が橙色に塗られる
- 自己ベスト: ふつう・タイムアタックそれぞれ（5問そろったゲームのみ）
- 記録はブラウザ（localStorage）に保存。別のブラウザやPCには引き継がれない。図鑑の「記録を消す」で消せる

## 要確認
- 対戦（同じ問題で点数勝負）を入れるか（今はデイリーの結果コピーで代用）
- タイムアタックの制限時間（20秒）とボーナス（1秒+50）
- 複数産地のお題の扱い（今は代表地点1つ）
- アニメ・漫画ジャンルを売り物にする場合の権利（作品名・キャラ名を文章で使うのみ。キャラの絵は使わない方針で）
